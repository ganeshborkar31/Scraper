# Source approval checklist

Before enabling a source, an administrator must verify its official documentation and terms/license; intended collection, retention, and reuse rights; geographic and record coverage; authentication requirements; rate/concurrency limits; attribution requirements; robots/access restrictions where relevant; deletion/retention requirements; secret handling; and contact/escalation procedures. Record the documentation URL, terms URL, license/attribution, allowed countries, connector configuration, and an owner. Explicitly approve and enable it only after review. Public visibility alone does not confer reuse permission. Never bypass login, paywalls, CAPTCHAs, bot defenses, or rate limits.

The shipped synthetic fixture is not real public business information. The dataset adapter is only for administrator-controlled local data with known rights. The initial enabled live source is OpenStreetMap through Overpass API, limited to small user-specified bounding boxes, allowlisted business tags, a 100-element output cap, and one serialized worker. It stores OSM element IDs and URLs with attribution; publicly used derived databases must account for ODbL share-alike terms. See [the OSM connector limits](openstreetmap.md). No other live provider is enabled.
